This will work in either absolute or relative mode. In absolute mode, putting the joystick into the upper left corner will put the cursor into the upper left corner of the screen.  Putting the joystick into the center will put the cursor into the center of the screen, etc.  In relative mode, moving the joystick to the left will make the cursor move to the left.  If it's in relative mode there are two numerical settings that affect the speed at which the cursor moves.  The speed is the base speed.  The acceleration is how much moving the joystick over affects the speed.  For instance, with a high acceleration, moving the joystick a little to the left will move at one speed and moving it all the way to the left will move at a higher speed.  You can also invert the Y axis.  If the Y axis is reversed, pulling the joystick back will make the cursor go up.  All of these values can be set by pulling down the File menu and choosing Options.

Current button settings:
Buttons 0 (trigger), 5, and 7 all do left click.
Buttons 1 and 6 both do right click.
Button 2 has the same effect as spinning the mouse wheel up one click.
Button 3 has the same effect as spinning the mouse wheel down one click.
Button 4 does a middle button click.
